# Earth density kernels for the inversion

Self-gravitating, compressible instantaneous-flow kernels for the Earth model, computed with
`fem_1d.self_gravity`, and their projection onto a radial basis (the forward operator, degree by degree).

| File | What it does |
|---|---|
| `earth_kernels.py` | Builds the non-dimensional Earth problem and writes `kernels_*.npz` (l = 2..lmax, about 0.1 s per degree) |
| `check_sia.py` | Compares the kernels with Sia's code on the same model |
| `project_basis.py` | Projects the kernels onto a radial basis: `G_l,j = int K_l phi_j dr`, writes `G_*.npz` |
| `plot_kernels.py` | Quick-look plot of a kernel file |
| `kernels_jump30.npz`, `G_jump30.npz`, `kernels_jump30.png` | Results for the x30 viscosity jump, l = 2..60 |

Run from this folder, e.g.

    python earth_kernels.py --sia ~/Documents/dev/lyness --lmax 60 --out kernels_jump30.npz
    python check_sia.py  --sia ~/Documents/dev/lyness --jump 30 --sia-layer
    python project_basis.py kernels_jump30.npz --layers-lower 18 --layers-upper 12 --out G_jump30.npz

(add `--fem <folder containing fem_1d>` if fem_1d is not installed).

## Model

- Radial model of Sia's code: PREM densities on 257 nodes, density linear within each layer, one finite element (degree 5) per layer;
  water 1030, core 9900 kg/m^3, core mass from GM_core.
- Viscosity relative to the upper mantle; x30 below the model node nearest 670 km (666 km). Density kernels depend only on the viscosity profile, not its scale.
- Fluid core (CMB mass sheet includes the core's response); ocean follows the geoid.
- Degree 1 is excluded (rigid-translation null mode).

## Observables and units

`J_lm = int K_l(r) drho_lm(r) dr` in metres, for `drho` in kg/m^3 and `r` in m; in the files,
`J = sum(weights * K[l] * drho(r))`.

| Key | Observable (positive up) |
|---|---|
| `h_b` | radial deflection of the surface, `-(T_b - rho_w Phi(b)) / ((rho(b) - rho_w) g(b))` |
| `N` | geoid height, `-Phi(b)/g(b)` (physics-sign potential) |
| `h_b_N` | seafloor height relative to the geoid, `h_b - N` |
| `h_c` | radial deflection of the CMB |

## Checks

- Kernels integrated against a density anomaly reproduce direct forward solves (units and factors).
- Converged to about 1e-8 in the polynomial degree, l = 2..60.
- Against Sia's code on the identical model (`--sia-layer`): within 3.6e-3 (geoid, l = 2), mostly about 1e-4, which is Sia's code's own discretisation error. With a sharp jump instead of Sia's code's averaged layer the geoid differs by up to 5e-3: the geoid is sensitive to how the jump is represented.
- Signs: constant viscosity gives an l = 2 geoid kernel negative at all depths; with the x30 jump it is positive in the upper mantle and negative in the lower mantle (Hager's classic result).
- `G c` equals a direct forward solve for a density in the basis to 1e-9, at l = 2, 10, 30, 60.

## Using G in pygeoinf

`G_<obs>[i]` is the row operator for degree `degrees[i]`, acting on the radial coefficients `c` of `drho_lm`;
the same row applies to every order m. G is defined against `dr`. If the radial model space uses
`<f, g> = int f g r^2 dr`, the representer of a datum is `K_l / r^2` and the Gram matrix is `M_r2dr`;
`M_dr` is the plain one. The default basis is piecewise linear, continuous except at the jump (two
coefficients there), 18 intervals below and 12 above; any other basis goes through `project(kernels, phi)`.
